# Viewo website

Static site for [Viewo](https://viewo.emedeiros.me/), hosted on GitHub Pages.

## Preview locally

From this repository, run:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Open [localhost:8765](http://localhost:8765/) and refresh after editing. Press Ctrl+C to stop the server.

## Brand assets

- `assets/img/logo-dark-background.svg` is the wordmark used in the header and footer of the home, privacy, support, and licenses pages.
- `assets/img/app-icon.png` is the 512 × 512 square mark used for the site's favicon, Apple touch icon, link preview, and landing-page artwork. It comes from `web/icon-512.png` in the Viewo brand kit.
